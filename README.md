## Landingpage de Organização de Eventos

Este é um projeto de uma landingpage para organização de eventos, onde é possível cadastrar eventos com informações como nome, data, tipo de evento, e número de convidados. O sistema persiste os dados no `localStorage` e está pronto para ser hospedado no [Netlify](https://www.netlify.com/).

##  Funcionalidades da Landingpage

. Cadastro de eventos com:
  - Nome do evento
  - Data
  - Tipo (casamento, festa, empresarial, reunião, outros)
  - Número de pessoas
.  Exibição dos eventos cadastrados em lista
.  Interface estilizada e colorida com CSS 
.  Armazenamento dos eventos via 'localStorage'
.  Hospedado na netlify
